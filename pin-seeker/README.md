# Pin Seeker

A standalone daily nine-hole timing golf game. No ads, no accounts.

- `npm install && npm run dev` to play locally
- `npm test` for the course/shot logic tests
- `npm run build` outputs a static site to `dist/` (deployed on Netlify)

Challenge links: `/?d=YYYY-MM-DD&beat=-5&by=Name` loads that day's course with a score to beat.
